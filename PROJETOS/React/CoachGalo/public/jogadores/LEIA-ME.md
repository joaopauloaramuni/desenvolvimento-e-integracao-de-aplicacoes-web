# Fotos dos jogadores

Coloque aqui as fotos oficiais com o nome `{id}.webp` (ou `{id}.png`) (o `id` de cada jogador no `src/data/elenco.json`),
por exemplo `fred.png`, `everson.png`, `renan-lodi.png`.

O app usa a foto desta pasta primeiro. Se ela não existir, carrega a foto direto do site do Atlético;
sem internet, mostra a silhueta listrada.
